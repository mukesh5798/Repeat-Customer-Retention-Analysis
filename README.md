# Repeat Customer & Retention Analysis

## Project Overview

This project analyzes repeat applications, customer activity,
and reapplication patterns to understand customer retention
and repeat behavior.

## Objectives

- Identify repeat customers
- Analyze repeat application patterns
- Measure customer retention
- Avoid duplicate customer counting
- Identify trends in customer activity

## Tools & Technologies

- Python
- Pandas
- Numpy
- Advanced Excel

## Key Analysis

- New vs Repeat Customers
- Repeat Application Rate
- Customer Retention
- Reapplication Trends
- Monthly Customer Activity

## Project Structure

- data/ – Dataset used for analysis
- python/ – Python analysis
- excel/ – Excel analysis

## Note

This project uses synthetic/anonymized data for portfolio
demonstration purposes. No confidential company data is included.
